2.1 Properties of Rational Expressions

1.

Fill in the blanks to make each statement true.

a) A rational expression is the quotient of two polynomials. The polynomial on the top is the ____________, and the polynomial on the bottom is the ____________.

b) The denominator of a rational expression cannot be ____________.

c) Division by 0 is ____________.

d) Writing a rational expression in lowest terms is called ____________.

Answer: a) numerator, denominator   b) zero (0)   c) undefined   d) simplifying
  1. These are the definitions at the start of section 2.1.
2.

Simplify the rational number −90126.

Answer: −57
  1. The GCF (Greatest Common Factor) of 90 and 126 is 18.
  2. 90 ÷ 18 = 5 and 126 ÷ 18 = 7, so −90126 = −57
3.

Determine the restriction(s) on x + 4x2 + 3x − 10.

Answer: x ≠ −5, x ≠ 2
  1. Set the denominator equal to zero: x2 + 3x − 10 = 0
  2. (x + 5)(x − 2) = 0, so x = −5 or x = 2
4.

Determine the restriction(s) on x − 2x2 + 16. Explain your answer.

Answer: There are no restrictions. The expression is defined for every real number.
  1. x2 + 16 = 0 gives x2 = −16
  2. A real number squared is never negative, so the denominator is never zero.
5.

Determine the restriction(s) on x + 12x2 − 7x + 3.

Answer: x ≠ 12, x ≠ 3
  1. 2x2 − 7x + 3 = (2x − 1)(x − 3)
  2. 2x − 1 = 0 gives x = 12; x − 3 = 0 gives x = 3
6.

Simplify x − 55 − x. State the restriction.

Answer: −1, x ≠ 5
  1. Factor −1 from the denominator: 5 − x = −(x − 5)
  2. x − 5−(x − 5) = −1
7.

Simplify x2 − xy − 2y2x2 − 4y2. State the restrictions.

Answer: x + yx + 2y, x ≠ 2y, x ≠ −2y
  1. Numerator: x2 − xy − 2y2 = (x + y)(x − 2y)
  2. Denominator: x2 − 4y2 = (x − 2y)(x + 2y)
  3. Restrictions come from the original denominator: x ≠ 2y, x ≠ −2y
  4. Divide out the common factor (x − 2y): x + yx + 2y
8.

Simplify 2x2 − 7x − 1525 − x2. State the restrictions.

Answer: −2x + 3x + 5, x ≠ 5, x ≠ −5
  1. Numerator: 2x2 − 7x − 15 = (2x + 3)(x − 5)
  2. Denominator: 25 − x2 = (5 − x)(5 + x) = −(x − 5)(x + 5)
  3. (2x + 3)(x − 5)−(x − 5)(x + 5) = −2x + 3x + 5
9.

Explain the error. A student wrote:   x2 + 5x2 + 2x = 52x

Then write the correct simplified form.

Answer: The student divided out x2, but x2 is a term, not a factor. The expression is already in lowest terms: x2 + 5x(x + 2), x ≠ 0, x ≠ −2
  1. The Fundamental Principle of Rational Expressions works only for common factors.
  2. x2 + 5 does not factor; x2 + 2x = x(x + 2)
  3. There is no common factor, so nothing can be divided out.
10.

The volume of a box is (3x2 + 14x + 8)(x + 2). The height of the box is 3x + 2. What is the area of the bottom of the box? Give the answer in expanded form.

Answer: (x + 4)(x + 2) = x2 + 6x + 8
  1. Volume = (area of bottom) × height, so area of bottom = volume ÷ height.
  2. 3x2 + 14x + 8 = (3x + 2)(x + 4)
  3. (3x + 2)(x + 4)(x + 2)3x + 2 = (x + 4)(x + 2) = x2 + 6x + 8

20.

A rectangle has area A = x2 + 7x + 10x2 − 9 square units and length L = x + 5x − 3 units. Find the width. Assume the denominators are not zero.

Answer: x + 2x + 3 units

  2. (x + 5)(x + 2)(x − 3)(x + 3) · x − 3x + 5
  3. Divide out (x + 5) and (x − 3): x + 2x + 3

2.3 Sums and Differences of Rational Expressions

21.

True or false? Explain your answer.   3x + 5x = 82x

Answer: False. The correct sum is 3x + 5x = 8x.
  1. With like denominators, add the numerators and keep the denominator. Do not add the denominators.
  2. Check with x = 2: left side = 32 + 52 = 4, right side = 84 = 2.
22.

Find the LCD (Least Common Denominator):   56x2y,   79xy3

Answer: 18x2y3
  1. 6 = 2 · 3 and 9 = 3 · 3, so the LCD of 6 and 9 is 18.
  2. Highest powers of the variables: x2 and y3. LCD = 18x2y3
23.

Find the LCD:   2x2 + x − 6,   34x − 8

Answer: 4(x − 2)(x + 3)
  1. x2 + x − 6 = (x + 3)(x − 2) and 4x − 8 = 4(x − 2)
  2. List each factor to its highest power: 4(x − 2)(x + 3)

29.

Simplify. Assume the denominators are not zero.

2x + 1 − 3x − 1 + 6x2 − 1

Answer: −1x + 1
  1. LCD = (x − 1)(x + 1)
  2. 2(x − 1) − 3(x + 1) + 6(x − 1)(x + 1) = 2x − 2 − 3x − 3 + 6(x − 1)(x + 1) = −x + 1(x − 1)(x + 1)
  3. −x + 1 = −(x − 1), so the answer is −1x + 1
30.

Tap A can fill a tank in t hours. Tap B can fill the same tank in t + 3 hours. Both taps are open. Write a simplified rational expression for the part of the tank that is filled in 2 hours.

Answer: 2(2t + 3)t(t + 3) of the tank   (also correct: 4t + 6t2 + 3t)
  1. In 1 hour, tap A fills 1t of the tank and tap B fills 1t + 3.
  2. In 2 hours: 2t + 2t + 3, LCD = t(t + 3)
  3. 2(t + 3) + 2tt(t + 3) = 4t + 6t(t + 3) = 2(2t + 3)t(t + 3)

2.4 Mixed Operations

31.

Answer: 2x

  2. 6x2 · x3 = 2x
  3. 4x − 2x = 2x

Simplify. Assume the denominators are not zero.

  2. 2x(x − 2)(x + 2) · (x − 2)(x + 2)x = 2
